# Detection-only development images

These original PNGs are referenced by
[the detection manifest](../manifests/digital-detection-v1.json). They contain
20 development images from seven source groups: six real games and one generated
training sequence captured with four style combinations in both orientations.

Expected rectangles were reviewed separately from detector outputs. Hashes,
conditions, source information and partition assignments live in the manifest.
Exact game URLs and FEN/PGN for user-supplied screenshots are not available.
No classification ground truth is asserted or generated by running recognition.

The eight held-out images live in `tests/fixtures/detection/held-out/`. All
variants of a source game stay together. Do not use held-out images to tune
thresholds or build templates. This corpus does not alter the separate frozen
80-position plan or the existing recognition fixtures.

See [detection methodology](../../docs/en/detection.md) and preserve the
[third-party notices](../THIRD_PARTY_NOTICES.md). Original cached files are kept;
these copies allow the regression suite to run from a fresh checkout.
